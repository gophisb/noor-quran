## 6. APK (M3)
### بناء آلي (الموصى به)
1. ادفع المشروع إلى GitHub (فرع `main`). سيعمل `Build Android APK` تلقائياً.
2. حمّل `houd11-apk` من Artifacts، أو ضع وسماً `git tag v0.3.0 && git push --tags` ليظهر في **Releases** مع `sha256`.
3. للتوقيع الدائم (حتى تُحدَّث النسخ فوق بعضها):
   `keytool -genkeypair -keystore noor.keystore -alias noor -keyalg RSA -keysize 2048 -validity 10000`
   ثم أضف الأسرار: `KEYSTORE_BASE64` (= `base64 -w0 noor.keystore`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
### بناء محلي
```
npm ci && npm run build
[ -f android/gradlew ] || npx cap add android
node RAFEEQ/scripts/prepare-android.mjs && npx cap sync android
cd android && ./gradlew assembleDebug        # يتطلب JDK 21 + Android SDK 35
```
