# ADR-001: حساب المواقيت محليًا بمكتبة `adhan` بدل API خارجي
- الحالة: مقبول — 2026-09-17
- السياق: المستخدم يشترط عمل التطبيق بدون إنترنت ودقة عالية في أي بقعة من الأرض.
- القرار: استخدام `adhan` (npm, MIT، مصانة، ~30KB، خوارزميات معتمدة من الهيئات الرسمية) + طرق إقليمية مخصصة (الأردن/فلسطين 18/18 +5 مغرب، المغرب 19/17، الجزائر 18/17، تونس 18/18، ليبيا 18.5/18.5) + `HighLatitudeRule.recommended`.
- الدليل: `RAFEEQ/scripts/verify-prayer-times.mjs` — PASS، أقصى انحراف 1 دقيقة عن AlAdhan في 5 مدن.
- البدائل المرفوضة: AlAdhan API (يحتاج إنترنت؛ نقطة فشل خارجية).
- خطة الخروج: الواجهة `computeTimes()` مستقلة؛ يمكن استبدال المكتبة دون مس المكوّنات.
