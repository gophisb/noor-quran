# ADR-005: التحويل إلى APK عبر Capacitor 7 + بناء آلي في GitHub Actions
- الحالة: مقبول — 2026-09-17
- السياق: المستخدم يريد APK محايداً قابلاً للتنزيل والتثبيت المباشر، غير مرتبط بأي متجر أو جهة.
- القرار:
  1. **Capacitor 7** (MIT، مصان، يغلّف نفس ملف `dist/index.html` في WebView أصلي). اخترنا 7 لا 8 لأن 8 يشترط Node ≥22 وبيئة البناء Node 20.
  2. `appId = app.houd11.quran`، لا تحليلات، لا SDKs طرف ثالث، لا خدمات Google Play. الصلاحيات: إنترنت، موقع، إشعارات، منبّه دقيق.
  3. **الأذان في الخلفية** عبر `@capacitor/local-notifications`: قناتان (أقصى/مدينة) بصوت الأذان من `res/raw`، جدولة 3 أيام تُجدَّد عند كل فتح/استئناف، `allowWhileIdle`. على أندرويد يُعطَّل مُجدوِل الويب لتفادي أذانين متزامنين.
  4. **قابلية إعادة التوليد:** كل تخصيصات Android نصّية (`prepare-android.mjs`) — الصوت يُفك من base64، الأيقونة Vector XML — لأن الملفات الثنائية لا تصمد في بيئة العمل (F-002/F-003).
  5. **البناء:** GitHub Actions يشغّل بوابة RAFEEQ ثم يبني `assembleRelease` موقّعاً بمفتاح المستودع (أسرار `KEYSTORE_*`)، أو بمفتاح مؤقت إن غابت، ويرفع `houd11.apk` + SHA-256 كـ Artifact وكـ Release عند وسم `v*`.
- الحزم المضافة (كلها MIT، من فريق Ionic/Capacitor الرسمي): `@capacitor/core` (الجسر)، `@capacitor/cli` (أدوات dev)، `@capacitor/android` (المنصة)، `@capacitor/app` (حدث resume لإعادة الجدولة)، `@capacitor/local-notifications` (أذان الخلفية). الإصدار 7.x.
- البدائل المرفوضة: PWA فقط (لا أذان بالخلفية موثوق)؛ Cordova (أقدم)؛ React Native (إعادة كتابة كاملة)؛ متاجر (تعارض شرط الحياد).
- قيود معروفة: على أندرويد 6–7 تُعرض أيقونة Capacitor الافتراضية (الأيقونة التكيفية من 8+). التلاوة تحتاج إنترنت. الإشعار بصوت الأذان يُقطع إن مسح المستخدم الإشعار.
- خطة الخروج: `dist/` مستقل تماماً عن Capacitor؛ حذف `android/` و`capacitor.config.ts` يعيد التطبيق ويباً خالصاً.
