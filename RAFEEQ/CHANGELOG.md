# CHANGELOG

## [0.3.0] — 2026-09-17 (M3: APK)
### Added
- تطبيق أندرويد أصلي عبر Capacitor 7 (`app.houd11.quran`)، أيقونة تكيفية، اتجاه عمودي.
- الأذان في الخلفية: إشعارات محلية مجدولة (3 أيام) بصوت الأذان من `res/raw`، قناة لكل مؤذن.
- `prepare-android.mjs` لإعادة توليد كل تخصيصات Android نصّياً؛ workflow `Build Android APK` مع توقيع وتحقق وRelease.
- الأذان مضمّن كـ base64 نصّي (يصمد في المستودع).
### Fixed
- تعارض مورد `ic_launcher_background` المكرر (اكتشفه بناء Gradle).

## [0.2.0] — 2026-09-17 (M2: الدقة والنظافة)
### Added
- طرق حساب إقليمية رسمية: الأردن/فلسطين، المغرب، الجزائر، تونس، ليبيا؛ `HighLatitudeRule.recommended`.
- `lib/compass.ts`: مصدر مطلق أولًا، تعويض دوران الشاشة، تنعيم دائري، مؤشر جودة/مصدر، تلميح «أدر يمينًا/يسارًا».
- فتح قفل الصوت عند أول لمسة لضمان الأذان التلقائي.
- حوكمة RAFEEQ V3 كاملة + 3 scripts تحقق.
### Changed
- كل الأرقام غربية 0-9 (`fmt`, `-u-nu-latn`). الموقع الافتراضي: القدس بطريقة الأوقاف الأردنية.
### Fixed
- انحراف 5 دقائق في مغرب القدس (F-001). استعادة أصول الأذان المفقودة (F-002).
